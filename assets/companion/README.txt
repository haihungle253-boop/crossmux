读书搭子 · 人设文件说明
Reading Companion · persona file
================================

把这个文件夹复制到 SD 卡根目录，路径变成：

    /companion/persona.txt

然后用任何文本编辑器直接改 persona.txt。改完保存即可，
不需要重新刷固件，下一次提问就会生效。

必须存成 UTF-8 编码。上限 1024 字节（中文约 340 字），
超出部分会被丢弃，不会报错。


写人设的四条经验
----------------

1) 描述「什么时候」，而不是「多少」。
   「幽默度极高」会让它每句都抖机灵；
   「该吐槽的时候别憋着」只在该吐槽的时候触发。

2) 给你最在意的那件事一个下限。
   并列六条要求，它只会做到两条，而且做哪两条不稳定。
   「每次至少落到一个具体的写作手法上」才是能执行的。

3) 允许它没话说。
   不是每章都有亮点。不给这个权利，它就会硬夸。
   一个逢章必夸的搭子，说什么你都不敢信。

4) 把理由一起写进去。
   只给规则，它会自己判断「这次情况特殊」；
   给了理由，它就知道破例的代价。


关于阅读进度
------------

你不需要在这里写「不要剧透」。

进度同步和防剧透是固件强制执行的：发出去的原文只到你
当前读到的位置为止，再往后的内容它根本看不到。这条规则
不会因为你怎么改这个文件而失效。


config.txt
----------

连接设置（服务地址、模型、访问凭证）放在同一个文件夹的
config.txt 里。没有这个文件，读书搭子就不会启用。

⚠ 这个文件是明文保存的。建议填一个只能访问你自己代理的
令牌，而不是服务商主密钥——卡丢了只需注销这一个令牌。


questions.txt
-------------

同一个文件夹里可以放 questions.txt，一行一个预设问题，
读书时直接选，不用打字。空行和以 # 开头的行会被忽略。
